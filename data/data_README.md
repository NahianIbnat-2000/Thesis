# Data

This directory holds the inputs and analysis-ready panels behind the thesis. The CEU institutional Refinitiv/LSEG subscription permits redistribution of the extracted series included here.

## Layout

```
data/
├── raw/                          # As-pulled source series (daily)
│   ├── bond_yield_data/          # Green & conventional 10Y yields, per country
│   ├── control_variables/
│   │   ├── vix/                  # CBOE VIX (FRED: VIXCLS)
│   │   ├── exchange_rate/        # USD/INR, USD/IDR, EUR/USD, USD/DKK
│   │   └── cds/                  # 5Y sovereign CDS spreads
└── processed/                    # Built by the notebooks from raw/
    ├── gdelt/                    # Daily V2Tone climate-news panel
    ├── regression/               # Asia regression panel + stacked DiD frames
    └── regression_europe/        # Europe benchmark equivalents
```

## Sources and frequency

| Series | Source | Frequency | Notes |
|---|---|---|---|
| Green & conventional bond yields | Refinitiv / LSEG Workspace (via CEU) | Daily | One strict 10Y twin pair per country; ISINs in filenames |
| Climate-news tone (V2Tone) | GDELT Project (Google BigQuery) | Daily | Regenerated by the GDELT notebook |
| VIX | FRED (`VIXCLS`) | Daily | |
| Exchange rates | Refinitiv / LSEG Workspace | Daily | |
| Sovereign CDS (5Y) | Investing.com | Daily | |

**Coverage:** 2020–2024. **Countries:** India, Indonesia (core); Germany, Denmark (benchmark).
**Excluded:** Thailand — no tradeable sovereign green bond with verifiable secondary-market yields on Refinitiv.

## Regenerating `processed/`

The processed panels are committed so the regressions run without re-pulling raw data. To rebuild them from `raw/`, run the notebooks in order (see the repository README, "How to reproduce"). The GDELT tone panel is regenerated from BigQuery by the GDELT notebook; the merged regression panels are built from `raw/` plus the GDELT output.
