# Corpus sources

The corpus is **not committed to this repository** — published papers and
official documents cannot be redistributed. Place the files below in this
folder locally, then run `python -m src.ingest`.

Suggested filename convention: `author_year_shorttitle.pdf` (the eval
harness matches expected sources on the leading author token).
